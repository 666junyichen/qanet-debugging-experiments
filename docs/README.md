# docs Folder

This folder contains public, anonymized technical summaries of the project.

本文件夹存放可公开的去标识化技术总结。

## Files

- `debugging-summary.md`: summarizes the debugging scope, bug categories, and system-level impact.
- `experiments-summary.md`: summarizes the controlled experiment setup, metrics, and findings.
- `experiment-notebook-summary.md`: replaces the raw notebook with a public workflow summary.
- `github-publishing-checklist.md`: lists safe-to-publish files, files to exclude, and repository naming suggestions.

## Public-Safety Rule

Do not add raw reports, student identifiers, institution names, course codes, private Drive links, datasets, checkpoints, or full experiment logs to this folder unless they have been reviewed and anonymized.
