# 项目说明

## 中文

项目名称：QANet Debugging and Controlled Experiments

时间：2026 年 3 月 - 2026 年 4 月

课程/活动/公司：Deep learning project phase; public version does not disclose institution or course identifiers.

我的角色：Deep learning debugging and experiment contributor

使用工具：Python, PyTorch, QANet, SQuAD v1.1, controlled experiments, F1, Exact Match (EM), validation loss analysis

我负责的内容：

- 参与修复 QANet 训练与评估流程，使原本无法正常运行的代码框架恢复为可训练、可评估的深度学习系统。
- 系统分析 pipeline-level bug，覆盖环境配置、forward pass、tensor shape、gradient flow、optimizer update、checkpoint loading 和 evaluation metric 计算。
- 系统分析 mechanism-level bug，覆盖 loss 与 pointer head 输出一致性、gradient clipping 位置、Adam/SGD 更新公式、scheduler 公式、attention mask、normalization、activation、initialization 和 answer-span decoding。
- 设计并执行控制变量实验，比较 dropout、learning rate 和 optimizer 对问答模型收敛行为与验证集表现的影响。
- 根据实验日志和 checkpoint 指标提炼模型表现，使用 F1、EM、development loss 和 checkpoint step 支撑结论。

数据来源：SQuAD v1.1 extractive question answering dataset.

分析方法：

- Debugging taxonomy: 将问题拆分为 pipeline-level 和 mechanism-level 两类，再按模块定位影响路径。
- Controlled experiments: 固定数据集、模型结构、训练预算和主要训练设置，只改变一个实验变量。
- Metric comparison: 比较 validation F1、Exact Match、development loss、best checkpoint step 和训练曲线趋势。

最终结果：

- 修复 24 个 pipeline-level defects，使训练、反向传播、参数更新、checkpoint 保存/加载和验证指标计算能够端到端运行。
- 修复 26 个 mechanism-level defects，提升优化过程、模型结构实现和评估输出的可靠性。
- Dropout 实验中，0.10 在测试值中表现最好，达到 F1 28.4401、EM 20.3333、development loss 5.7477。
- Learning rate 实验中，0.002 在测试值中表现最好，达到 F1 28.8104、EM 22.0000、development loss 5.5529。
- Optimizer 实验中，Adam 明显优于 SGD：best dev F1 为 29.40 vs 6.68，best dev EM 为 21.92 vs 1.25；final evaluation F1 为 25.73 vs 2.77。

可以写进简历的量化成果：

- Debugged a PyTorch QANet question-answering pipeline by fixing 50 implementation defects across execution, optimization, model mechanisms, and evaluation.
- Restored an initially non-runnable model into a trainable experiment system with checkpointing and validation metrics.
- Designed controlled experiments across 3 core training factors: dropout, learning rate, and optimizer selection.
- Improved experiment interpretability by comparing F1, EM, validation loss, checkpoint step, and convergence behavior under fixed training budgets.

Project name: QANet Debugging and Controlled Experiments

Timeline: March 2026 - April 2026

Project phase: Deep learning project phase; public version does not disclose institution or course identifiers.

Role: Deep learning debugging and experiment contributor

Tools: Python, PyTorch, QANet, SQuAD v1.1, controlled experiments, F1, Exact Match (EM), validation loss analysis

Responsibilities:

- Contributed to restoring a broken QANet training/evaluation framework into a trainable and measurable deep learning system.
- Analyzed pipeline-level failures across environment setup, forward pass execution, tensor shape flow, gradient propagation, optimizer updates, checkpoint loading, and evaluation metrics.
- Analyzed mechanism-level failures across loss/output consistency, gradient clipping order, Adam/SGD update rules, scheduler formulas, attention masks, normalization, activation, initialization, and answer-span decoding.
- Designed and ran controlled experiments to compare how dropout, learning rate, and optimizer choice affect convergence and validation performance.
- Summarized experimental evidence using F1, Exact Match, development loss, best checkpoint step, and training-curve behavior.

Data source: SQuAD v1.1 extractive question answering dataset.

Methods:

- Debugging taxonomy: grouped issues into pipeline-level and mechanism-level categories, then traced their module-level effects.
- Controlled experiments: fixed dataset, model architecture, training budget, and major settings while varying one factor at a time.
- Metric comparison: compared validation F1, Exact Match, development loss, best checkpoint step, and convergence trends.

Final outcomes:

- Fixed 24 pipeline-level defects and restored end-to-end training, backpropagation, parameter updates, checkpoint handling, and validation metric computation.
- Fixed 26 mechanism-level defects affecting optimization reliability, model-structure correctness, and evaluation output quality.
- Dropout 0.10 was the best tested dropout value, reaching F1 28.4401, EM 20.3333, and development loss 5.7477.
- Learning rate 0.002 was the best tested learning rate, reaching F1 28.8104, EM 22.0000, and development loss 5.5529.
- Adam clearly outperformed SGD: best dev F1 29.40 vs 6.68, best dev EM 21.92 vs 1.25; final evaluation F1 25.73 vs 2.77.
