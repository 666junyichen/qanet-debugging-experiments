# artifacts Folder

This folder is reserved for small, anonymized artifacts that are safe to publish, such as cleaned metric tables or selected plots.

本文件夹用于存放体积较小、已匿名化且适合公开的结果文件，例如清理后的指标表或精选图表。

## What Can Be Added

- Clean CSV or JSON metric summaries without personal identifiers.
- Exported plots that do not show private paths, names, course identifiers, or account information.
- Small examples that demonstrate model behavior without including restricted datasets or model weights.

## What Should Not Be Added

- Raw datasets.
- Model checkpoints or trained weights.
- Full training logs with private paths or account names.
- Original reports containing names, student IDs, course codes, or institution names.
- Private Google Drive links.
