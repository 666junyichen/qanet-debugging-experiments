# reports Folder

This folder stores public-facing report summaries only.

本文件夹只存放可公开的报告摘要。

## Important

The original PDF report contains personal identifiers, institution metadata, course identifiers, and submission details. It should not be uploaded to a public GitHub repository in its original form.

原始 PDF 报告包含个人标识、机构信息、课程标识和提交信息，不建议以原始形式上传到公开 GitHub 仓库。

Use `public-report-summary.md` as the publishable replacement.
